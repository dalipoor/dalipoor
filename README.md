## What I'm building

### Tradedge Labs

**A trading analytics SaaS** that helps traders understand their performance and identify patterns in their trading.

- Imports broker CSV exports from Schwab, Webull, Robinhood, Public.com, and Interactive Brokers, with support for manual data entry.
- Tracks P&L, win rate, profit factor, drawdown, and performance over time, with AI-powered analysis of trading patterns.
- Isolates each user's data through PostgreSQL row-level security.
- Integrates Stripe subscriptions, market alerts, and external uptime monitoring through GitHub Actions.

[Explore Tradedge Labs](https://tradedgelabs.com) · [View the project](https://github.com/dalipoor/Tradedge-Labs)

### Automated Options Trading & Research System

**A private Python system** for researching trading strategies and automating execution.

- Scans markets, executes orders, and monitors positions through the Schwab API using OAuth 2.0.
- Uses point-in-time backtesting to evaluate strategies using only information available at each historical decision.
- Maintains a concurrency-safe trade journal with file locking and atomic writes.
- Includes a Flask monitoring dashboard and automated regression checks.
- Runs on macOS with launchd and AWS Lightsail with systemd.

*Source code is private.*
